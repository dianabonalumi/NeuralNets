# Matrix Solver Implementations

## Overview
This directory contains the repositories and source code for the various matrix solver implementations developed for this project.

## Documentation Guidelines
For each solver implementation, a detailed report must be included. Please adhere to the following standards:

* **Format:** The documentation must be provided as a **PDF file**, generated using **LaTeX**.
* **Performance Analysis:** The report must include a detailed performance evaluation, specifically covering:
    1.  **Baseline Comparison:** Performance results compared against the reference solver provided by the professor.
    2.  **Weak Scalability:** Analysis of how the solver handles increased problem sizes proportional to the increase in resources.
    3.  **Strong Scalability:** Analysis of how the solver performs with a fixed problem size as resources increase.

## Purpose
The goal of this documentation is to:
* Track the design process and architectural decisions.
* Facilitate the understanding of the codebase for current and future implementers.
